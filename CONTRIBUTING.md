# Contributing

Thank you for taking the time to look at DexTor OS for Windows.

This repository is a published copy of our source code, so that anyone can see exactly what
the launcher does. Development happens in our own repository, and each release is copied here.

## What we welcome

- **Bug reports** - [open a bug report](https://github.com/dextoros/dextor-launcher/issues/new?template=bug_report.yml).
  The wizard can save a diagnostic report; attaching it helps a lot. Please remove anything
  personal from it first.
- **Ideas and feature requests** - [suggest a feature](https://github.com/dextoros/dextor-launcher/issues/new?template=feature_request.yml).
- **Questions about how something works** - open an issue; if the answer belongs in the
  documentation, we will add it there.

Please search the existing issues before opening a new one, and write in English so that
everyone can follow the discussion.

## Pull requests

We do not accept pull requests, and they are closed automatically. The code is under the
[PolyForm Strict License](LICENSE), which does not allow changes or derivative works, and we
cannot take in code whose origin we have not reviewed. If you have found a fix, describe it in an
issue - we are glad to apply it ourselves and credit you in the release notes.

## Security

Please do not report vulnerabilities in public issues. See [SECURITY.md](SECURITY.md).
